# Olive Press Tycoon

A 3D idle tycoon game: run Abu Yousef's olive press, from a village stone mill to an export brand.
Installable web app (PWA): open the site on your phone and choose "Install" / "Add to Home screen".

Plain HTML + [three.js](https://threejs.org) r147, no build step. `sw.js` caches everything for offline play.
